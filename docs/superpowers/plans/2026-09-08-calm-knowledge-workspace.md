# Calm Knowledge Workspace Implementation Plan

**Goal:** Redesign NusaPolicy Copilot into a calm, light B2B knowledge workspace that makes RAG evidence understandable for HRD and non-technical users.

**Architecture:** Preserve existing Next.js routes and browser-to-FastAPI contracts. Replace only the frontend visual system: a warm neutral base, navy ink, one muted teal accent, restrained serif/sans typography, and compact evidence-first components.

**Tech Stack:** Next.js 14, React 18, TypeScript, Tailwind CSS 3, existing API client.

**Spec:** User-selected “Option A — Calm knowledge workspace” with light editorial details from this conversation on September 8, 2026.

## Constraints

- Remove dark glassmorphism, indigo/purple AI gradients, neon glow, and repeated all-caps labels.
- Preserve chat, citations, refusal status, feedback, document catalog, and re-index controls.
- Use one accent family: muted teal.
- Keep motion subtle or absent; clarity is more important than spectacle.
- Do not commit until the user completes visual and functional review.
